# 服务端维护与同步

本页对应尚未发布的维护功能。管理员可在 Web 端“我的 → 服务端维护”进入，配套 Flutter 客户端也提供同名入口，普通账号不可访问管理接口。

## 缓存与变更通知

书籍、章节、已读和书签在数据库提交后更新对应版本；账号设置变化也更新该账号的阅读版本。客户端打开书籍时校验 `/api/books/:id/revision`，未变化时复用详情缓存，变化时后台更新。WebSocket 每 5 秒检查已连接账号的版本，只在变化时通知；客户端恢复前台或每分钟通过 `/api/sync/state` 补充校验。

普通进度上传仅推进进度版本，不引发整库元数据刷新。书架、详情和书签收到通知后刷新数据，尽量保留分页、展开和滚动状态。旧服务端不支持校验接口时，Flutter 客户端继续使用原来的刷新方式，关于页的强制刷新仍可使用。

## 数据库备份与恢复

- 默认每 24 小时自动备份，保留最近 7 份；间隔可设为 1–168 小时，自动备份保留数为 1–60。开启服务后第一次定时检查在约 1 分钟后执行。
- 使用 SQLite 在线备份，包含已提交到 WAL 的数据。备份位于数据库旁的 `<数据库文件名>.backups`，应随数据目录一起持久化。
- 手动备份、升级前和恢复前快照不会被自动保留策略删除。自动备份仅在新备份成功后清理超出保留数量的旧自动备份。
- 备份包含数据库中的账号、进度、已读、书签和数据库内设置；**不包含音频、外部 `config.toml`、插件文件或机器标识**。敏感凭据使用与机器及数据库路径关联的密钥加密，跨机器或变更数据库路径恢复后，可能需要重新填写 WebDAV、插件等凭据。
- 导入文件先执行完整性与结构版本检查，来自更新数据库结构的备份会被拒绝。上传上限 512 MiB；反向代理也须允许对应请求大小。
- 恢复需要输入“恢复备份”，只暂存请求，**下次服务端启动、建立连接池之前**应用。运行中的数据库不会直接替换；重启前可取消。恢复前先保存当前数据库快照。恢复后账号、密码或登录状态可能回到备份时的状态，需要重新登录。
- Flutter 客户端下载导出的备份上限为 64 MiB，较大备份请在服务端 Web 页面下载；原生客户端导入使用文件流。Flutter Web 流式上传若遇到会话失效，可重新选择文件重试。
- 备份包含账号资料，请妥善保管导出的文件，并定期将备份复制到另一台设备。相同磁盘上的快照不能应对磁盘损坏。

## 多端进度保护

`GET /api/progress/:bookId` 返回同一快照中的 `revision`，即使从未播放也返回版本 0 和位置 0。新客户端提交进度时附带 `base_revision` 与 `device_id`，服务端在同一个写事务内比较版本并保存进度；成功后版本递增，过期提交返回 HTTP 409：

```json
{"code":"PROGRESS_CONFLICT","message":"其他设备已更新进度，请选择续播位置","current":{"book_id":"book","chapter_id":"chapter","position":120,"revision":8}}
```

冲突提交不改变续播位置或收听统计。客户端保留本机待同步进度，用户可采用远端位置，或明确选择本机位置后以最新版本重新提交。再次发生并发更新时，服务端仍会拒绝，避免静默覆盖。清除播放进度也会使旧版本失效。

旧客户端未传 `base_revision` 时仍可写入，兼容已有版本；严格的版本冲突保护需要新版服务端与新版客户端配合使用。普通标记已读继续使用独立接口，不改变续播位置。

## 预加载、缓存和诊断

服务端维护页可配置每章预加载 1–16 MiB、内存总量 4–256 MiB、空闲有效期 5–3600 秒、磁盘章节数 1–500，以及可选的 64–65536 MiB 磁盘上限。留空磁盘上限时沿用原配置。默认值保持原来的 4 MiB、32 MiB、60 秒和 50 章。修改预加载参数会清空临时预加载并取消相关后台任务；磁盘限额按现有缓存淘汰规则生效。

这里管理的是服务端缓存，与客户端“下载设置”中的 Wi-Fi 自动下载、已听自动删除相互独立；是否自动预加载继续遵循账号播放设置。诊断中的命中/未命中次数从服务端本次启动开始累计。

故障诊断可检查数据库响应、数据/临时/备份目录可写性、媒体工具，以及各存储库的目录连接和最多 64 KiB 的章节读取。本地和 WebDAV 使用已有存储访问方式，不会触发整库扫描。可用空间目前在 Unix 系统返回，Windows 无法取得时显示为空；检查结果不代表整库每个文件都能读取。

## 接口入口

除两个版本接口外，下列接口仅管理员可调用：

| 接口 | 用途 |
| --- | --- |
| `GET /api/sync/state` | 当前账号的全局内容与阅读版本 |
| `GET /api/books/:id/revision` | 有权访问书籍的内容、阅读与进度版本 |
| `GET/PUT /api/system/maintenance` | 读取和保存维护策略 |
| `GET/POST /api/system/backups` | 列出/创建备份 |
| `POST /api/system/backups/import` | 上传并校验数据库备份 |
| `GET/DELETE /api/system/backups/:id` | 下载/删除备份 |
| `POST /api/system/backups/:id/restore` | 校验并暂存恢复请求 |
| `DELETE /api/system/backups/pending-restore` | 取消恢复请求 |
| `GET /api/system/diagnostics` | 服务端环境诊断 |
| `POST /api/system/diagnostics/libraries/:id` | 存储库连接与章节抽样诊断 |
